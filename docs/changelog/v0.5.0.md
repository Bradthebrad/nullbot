# NullBot v0.5.0

The agent runtime, terminal UI and, new in this release, a headless CLI.
NullBot's desktop app ([NullBot UI v0.5.0](https://github.com/Bradthebrad/nullbot_ui/releases/tag/v0.5.0))
is built on this version.

## Highlights

- **Headless runs.** `nullbot -p "request"` runs one request and prints the
  answer; `nullbot -p -` reads it from standard input; `nullbot serve` runs
  scheduled tasks and answers each line of standard input. `--json` prints the
  answer, status and tool calls as JSON, `--activity` streams progress to
  standard error, and `--project` and `--model` override the project and the
  manager's model for one run. Exit status: 0 done, 1 failed, 2 usage error,
  130 interrupted. See [docs/HEADLESS.md](https://github.com/Bradthebrad/nullbot/blob/main/docs/HEADLESS.md).
- **Interactive visuals.** The `visualize` and `visualize_results` tools show
  the person a poll, web page or prototype, picture to label, chart, draw.io
  diagram or project file in the desktop app and return their answer, note and
  recorded interactions. Visuals are saved per project and signed. See
  [docs/VISUALS.md](https://github.com/Bradthebrad/nullbot/blob/main/docs/VISUALS.md).
- **Per-project permissions for every tool.** Built-in tools and local or
  remote MCP servers are all checked against the project a call touches (read
  only, read & write, full, custom). What a tool needs comes from your per-tool
  setting, NullBot's knowledge of its own tools, or the server's hints and the
  tool's name, and defaults to write. Paths outside every project are refused
  before any file access.
- **Run control.** Pause, stop after the current step, stop everything, steer
  the manager or one subagent, and ask on the side. Steps are checked before
  every model call and tool call, so pause and stop take effect between tool
  calls.
- **Context sized per model.** Two-tier management: shorten tool results the
  model has read from 60% of the window, summarize older messages from 85%,
  and cut any tool result that wouldn't fit to a preview with its size. Context
  windows come from the provider, a built-in table or your override. `/compact`
  runs the same passes on demand.
- **Searchable history.** Sessions save their tool calls, and agents can
  search everything with `history_search` and read any part of a session with
  `history_session_read`.
- **MCP session pool.** Enabled servers start once, in parallel, and are
  shared by the manager, subagents and side questions; they restart after a
  crash and stop when idle.
- **Service accounts.** Gmail (API or IMAP/SMTP), Outlook, Google Drive,
  OneDrive, iCloud Drive folders, Twilio, WhatsApp Business, Discord, Telegram
  and a local Signal bridge, stored with Windows DPAPI and passed only to the
  matching server installed from the Marketplace. The email, drives and
  messages servers are not released yet.
- **Marketplace.** New skill packs: web search, web tools, browser automation
  and browser research.
- **Skills by name.** A message that starts with `/skill-name` is sent with
  that skill selected.

Built on [tinychain v0.3.0](https://github.com/Bradthebrad/tinychain/releases/tag/v0.3.0):
the step gate, two-tier context management, and MCP spec metadata, multiplexed
stdio, roots, remote sessions and process-tree kill.

## Downloads

| File | Platform |
| --- | --- |
| `nullbot.exe` | Windows x64 |
| `nullbot-small.exe` | Windows x64, compressed with UPX for a smaller download |
| `nullbot-windows-arm64.exe` | Windows on Arm |
| `nullbot-linux-amd64` | Linux x64 |
| `nullbot-linux-arm64` | Linux on Arm |
| `nullbot-darwin-amd64` | macOS on Intel |
| `nullbot-darwin-arm64` | macOS on Apple silicon |
| `SHA256SUMS.txt` | SHA-256 checksums for all of the above |

Each file runs the terminal UI, or headless with `-p` or `serve`. On Linux
and macOS, make the file executable (`chmod +x`); macOS may need the download
quarantine removed (`xattr -d com.apple.quarantine nullbot-darwin-arm64`)
because the binaries aren't signed. Antivirus tools and SmartScreen
sometimes flag UPX-compressed executables; if `nullbot-small.exe` is blocked,
use `nullbot.exe`. The desktop app is a separate download.

## Validation and limitations

Checked for this release: the Go test suites of NullBot and tinychain on
Linux, cross-compiled builds for all six targets, a headless smoke test of
`version`, `help`, `-p` and `--json`, and pattern scans of the source and
history for credentials and personal data. Live providers and the terminal UI
on each platform were not exercised by these checks. Visuals need the desktop
app; the terminal UI and headless runs don't offer them.
